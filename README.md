# Утренняя сводка

Каждое утро около 8:00 в Telegram приходит одно сообщение: погода в Варшаве, события из Google Календаря, дни рождения на неделю вперёд и дедлайны из Google Задач.

Работает на Google Apps Script: без сервера, бесплатно и даже когда компьютер выключен. ИИ не используется — только сбор и разбор данных.

## Как выглядит

```
Доброе утро! Пятница, 9 октября

☁️ Варшава: сейчас +10° (ощущается +6°), днём +10…+14°
Пасмурно
💨 Порывы ветра до 53 км/ч

📅 Сегодня
• Весь день: Праздник
• 10:00–11:00 Созвон с клиентом
• 15:30–16:30 Стоматолог

🎂 Дни рождения
• Сегодня: Андрей
• Вт, 13 окт (через 4 дня): Мама

⏰ Дедлайны
• ❗ Просрочено с 7 окт: Оплатить интернет
• Сегодня: Сдать проект
• Вс, 11 окт: Купить подарок
```

## Откуда данные

| Блок | Источник |
|---|---|
| Погода | [Open-Meteo](https://open-meteo.com), без ключа. Прогноз с текущего часа до 22:00: ночной дождь, который уже прошёл, не считается. Зонт — если вероятность осадков от 50%, ветер — если порывы от 50 км/ч |
| События | Все календари, отмеченные галочкой в Google Календаре. Без отклонённых, уже закончившихся и дублей |
| Дни рождения | Дни рождения контактов из Google Календаря на 7 дней вперёд |
| Дедлайны | Google Задачи: в приложении Google Календарь «+» → «Задача», указать дату. Просроченные и на 7 дней вперёд |

Если один источник недоступен, сводка всё равно придёт, а в этом блоке будет написано, что пошло не так.

## Установка (один раз, минут 10)

1. **Бот.** В Telegram открой [@BotFather](https://t.me/BotFather) → `/newbot` → получишь токен. Сразу напиши своему боту любое сообщение.
2. **Apps Script API.** Открой [script.google.com/home/usersettings](https://script.google.com/home/usersettings) и включи «Google Apps Script API».
3. **Код в Google.** В папке проекта:
   ```bash
   npm install
   npm run login    # откроется браузер — войди в Google
   npm run create   # создаст проект Apps Script
   npm run push     # зальёт код
   npm run open     # откроет редактор
   ```
4. **Токен.** В редакторе: ⚙️ «Настройки проекта» → «Свойства скрипта» → добавить свойство `TELEGRAM_TOKEN` со значением токена.
5. **Запуск.** Вверху выбери функцию `setup` → «Выполнить» → разреши доступ. Google предупредит, что приложение не проверено: это твой собственный скрипт, жми «Дополнительные настройки» → «Перейти».
6. В Telegram придёт пробная сводка. Дальше она будет приходить каждый день около 8:00.

## Функции в редакторе

- `setup` — первый запуск: запоминает чат, ставит ежедневный триггер, шлёт пробную сводку. Запускать повторно безопасно.
- `sendDigest` — отправить сводку прямо сейчас.
- `previewDigest` — показать сводку в журнале выполнения, ничего не отправляя.
- `resetChat` — забыть чат, чтобы переключить сводку на другой.

## Настройки

Всё в [`src/Config.js`](src/Config.js): город и координаты, час отправки, пороги для зонта и ветра, какие календари брать, на сколько дней вперёд показывать дни рождения и дедлайны. После правок — `npm run push`. Если поменял час отправки, запусти `setup` ещё раз.

Время срабатывания плавает в пределах ±15 минут — так устроены триггеры Apps Script.

## Разработка

- `npm test` — тесты: код из `src/` запускается локально с заглушками сервисов Google и Telegram.
- `npm run preview` — сводка на демо-данных прямо в терминале.
- `npm run push` — залить изменения в Google.

## Безопасность

- Токен бота хранится только в свойствах скрипта, в репозитории его нет.
- Доступ к календарю и задачам — только на чтение.
